RankPatch 0.1.0 maintains the exact combined top-k as workers replace or retract their ranked lists.

- Embed the C++17 header or install the Python source distribution with a C++17 compiler.
- Run the browser demo on Hugging Face or pipe your own source revisions into the JSON Lines example.
- Reproduce the 18-scenario comparison and the pinned SciFact replay from the source archive.
