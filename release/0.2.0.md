# RankPatch 0.2.0

This release packages the string-ID catalog adapter with the existing native index.
Use `from rankpatch.catalog import CatalogFusion, DocumentCatalog` to share a
document mapping across queries. Each query owns its scores and source revisions.
Both buffered and steady strategies support replacements, retries and withdrawals.

Install the wheel for your Python and platform with:

```sh
python -m pip install --no-index --only-binary=:all: --find-links https://github.com/pgg898200-ship-it/rankpatch/releases/expanded_assets/v0.2.0 rankpatch==0.2.0
```

The source distribution supports builds with a C++17 compiler. The integer-ID
API and its default buffered strategy are compatible with 0.1.0.
